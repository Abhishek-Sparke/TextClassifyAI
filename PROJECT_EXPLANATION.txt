PROJECT EXPLANATION: CLASSIFYING TEXT DOCUMENTS USING MACHINE LEARNING
================================================================================

1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
This project is an end-to-end Natural Language Processing (NLP) and Machine
Learning system for automated multi-class text document categorization, model
benchmarking, and real-time interactive inference.

With unstructured text growing across news feeds, enterprise knowledge bases, 
and digital repositories, manual document classification is costly and unscalable.
This project automates classification by converting raw text into numeric feature
vectors, training multiple supervised machine learning models, evaluating their
performance, and deploying the solution through modern interactive interfaces.

3. DATA PREPROCESSING PIPELINE
--------------------------------------------------------------------------------
Located in: src/preprocessing.py

Raw text documents undergo multi-stage linguistic cleaning:
1. Missing Value Filtering: Null, non-string, or empty entries are rejected.
2. Case Normalization: All characters converted to lowercase.
3. Artifact Removal: Regex patterns strip out email addresses, URLs, and residual
   header tokens (e.g., 'From:', 'Subject:', 'Lines:').
4. Punctuation & Noise Stripping: Symbols, special punctuation, and non-ASCII
   glyphs are removed.
5. Tokenization: Words are tokenized matching alphabetic strings with length >= 2.
6. Stopword Removal: Common non-discriminative English words ("the", "is", "at",
   "which") are removed using the NLTK English stopwords list.
7. Lemmatization: Words are reduced to canonical dictionary base forms using NLTK's
   WordNetLemmatizer (e.g., "studying" -> "study", "spaceships" -> "spaceship"),
   with PorterStemmer as an automatic fallback.


4. FEATURE EXTRACTION (TF-IDF)
--------------------------------------------------------------------------------
Located in: src/features.py

Text cannot be ingested directly into linear models; it must be mapped into
numerical vectors using Term Frequency - Inverse Document Frequency (TF-IDF).

- Configuration:
    * N-gram Range: (1, 2) - captures both individual words and 2-word phrases
      (e.g., "space shuttle", "computer graphics", "home run").
    * Maximum Features: 5,000 top vocabulary terms.
    * Sublinear TF: Replaces term frequency tf with 1 + log(tf), mitigating
      skew from heavily repeated words in lengthy documents.
    * Minimum Document Frequency (min_df): 2 occurrences across the corpus.
    * Normalization: L2 Euclidean norm so vector length does not bias results.

- Data Leakage Guard:
    * The vectorizer is strictly 'fit' on the training split ONLY.
    * Test data and live user inputs are strictly 'transformed' using the learned
      vocabulary and IDF weights.


5. MACHINE LEARNING CLASSIFIERS & BENCHMARKS
--------------------------------------------------------------------------------
Located in: src/models.py and src/evaluate.py

Four distinct supervised algorithms are trained and compared on the 100,000-document corpus:

1. Support Vector Machine (LinearSVC + CalibratedClassifierCV)
   - Finds maximum-margin hyperplanes separating category vector clouds.
   - Calibration: Wrapped with CalibratedClassifierCV (sigmoid / Platt scaling)
     to generate calibrated class probabilities.
   - Outcome: Best performing model across all 26 categories (91.32% accuracy, 91.08% F1-score).

2. Logistic Regression (LogisticRegression)
   - Linear discriminative classifier with cross-entropy loss.
   - Regularization: L2 penalty (C = 1.0), solver = 'lbfgs'.
   - Strengths: High interpretability, well-calibrated confidence probabilities.
   - Outcome: Runner-up model with 90.64% accuracy and 90.26% F1-score.

3. Multinomial Naive Bayes (MultinomialNB)
   - Probabilistic generative model using Bayes' theorem with word independence.
   - Smoothing: Laplace smoothing (alpha = 0.1).
   - Strengths: Extremely fast training (0.068s), low memory footprint.
   - Outcome: Highly competitive with 90.55% accuracy and 90.35% F1-score.

4. Random Forest (RandomForestClassifier)
   - Ensemble of 80 randomized decision trees (max_depth = 25).
   - Strengths: Non-linear decision boundaries, resists extreme outliers.
   - Outcome: 71.59% accuracy and 64.68% F1-score.

Experimental Results on 20% Test Split (19,998 Unseen Documents across 26 Classes):
+---------------------------+----------+-----------+--------+----------+---------------+
| Model                     | Accuracy | Precision | Recall | F1-Score | Training Time |

6. MODEL EXPLAINABILITY & FEATURE ATTRIBUTION
--------------------------------------------------------------------------------
To prevent "black-box" decision making, the system provides transparent explainability:
1. Global Class Salience: Mean TF-IDF scores identify the strongest discriminative
   vocabulary terms per class (e.g., 'orbit', 'nasa', 'launch' for Space Science).
2. Local Document Attribution: For every prediction, the top TF-IDF terms from the
   submitted document are highlighted with their relative weights, explaining exactly
   why the classifier reached its conclusion.


7. APPLICATION ECOSYSTEM & DEPLOYMENT
--------------------------------------------------------------------------------
The project provides two independent user interfaces:

A. Streamlit Web App (app.py)
   - Self-contained web interface with custom dark AI SaaS aesthetic.
   - Features:
       * Live document classification with confidence meters.
       * Probability distribution breakdown across all 26 categories.
       * Top extracted keyword tags with TF-IDF weights.
       * Interactive Model Comparison & Benchmark tables.
       * Dataset Explorer with class distributions and length histograms.
       * Confusion Matrix heatmaps.
   - Live URL: https://abhishek-sparke-mlproj-app-cmlulp.streamlit.app/

B. Decoupled Web Stack
   - Backend API (server.py):
       * Built with Starlette and Uvicorn.
       * Exposes /api/health and /api/classify endpoints.
       * Returns predictions, probabilities, extracted keywords, and latencies.
   - Frontend Dashboard (frontend/):
       * Modern Single Page Application built with React, Vite, and Tailwind CSS.
       * Modular components: Playground, ModelBenchmarks, ConfusionMatrix,
         DatasetExplorer, PipelineViewer.
